# Product Overview

ConstructLM is a privacy-first, browser-based RAG (Retrieval-Augmented Generation) workspace designed for construction professionals and technical documentation workflows.

## Core Value Proposition

- All document processing and embeddings happen locally in the browser using Transformers.js
- No data leaves the user's device - documents and embeddings stored in browser IndexedDB
- API keys stored locally in localStorage
- Multi-model AI support (Gemini, Cerebras, Groq, OpenRouter, Ollama)
- Interactive code canvas with production-grade runtime bundler for React/TSX components

## Key Features

1. **Document Management**: Upload TXT, MD, CSV, JSON, PDF files for RAG context
2. **Local Embeddings**: Xenova/all-MiniLM-L6-v2 model runs entirely in browser
3. **Multi-Model Chat**: Switch between AI providers in real-time
4. **Vision Support**: Image analysis with Gemini models
5. **Code Canvas**: Live preview and editing of React/HTML components with full bundling
6. **Session Management**: Save, export, and switch between chat sessions
7. **Source Citations**: Every AI response includes source references with similarity scores

## Target Users

- Construction professionals working with technical documentation
- Developers needing local RAG capabilities
- Users requiring privacy-first AI interactions
- Teams working with sensitive documents that cannot be uploaded to cloud services
