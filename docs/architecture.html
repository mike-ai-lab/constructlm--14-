Architecture

ConstructLM is built with modern web technologies and a privacy-first architecture. This guide explains the technical design and component structure.

Technology Stack

Frontend

  • React 19: UI framework with hooks and functional components
  • TypeScript: Type-safe development
  • Vite: Fast build tool and dev server
  • Tailwind CSS: Utility-first styling

AI & Machine Learning

  • Transformers.js (@xenova/transformers): Local embeddings
  • Google Gemini API: AI chat responses
  • Cerebras AI API: Fast AI chat responses

Storage & Data

  • IndexedDB: Vector database and document storage
  • localStorage: API keys and preferences

Rendering & Formatting

  • react-markdown: Markdown rendering
  • remark-gfm: GitHub Flavored Markdown support
  • lucide-react: Icon library

Component Architecture

App.tsx

Root component managing:

  • Application state (files, messages, settings)
  • Sidebar resize logic
  • Mobile gesture handling
  • Chat session management
  • API key configuration

ChatInterface.tsx

Handles conversation display:

  • Message rendering with markdown support
  • Citation display and tooltips
  • Input field with submit handling
  • Auto-scroll to latest message
  • Streaming response updates

Sidebar.tsx

Manages documents and chats:

  • Tab switching (CHATS / SOURCES)
  • File upload handling
  • Document enable/disable toggles
  • Chat session list
  • Context usage meter

SettingsModal.tsx

API configuration interface:

  • API key input fields
  • Show/hide password toggles
  • Key validation and testing
  • Save to localStorage

Service Layer

embeddingService.ts

Local embedding generation:

class EmbeddingService {
  - loadModel(): Downloads and caches Transformers.js model
  - generateEmbedding(text): Creates 384-dim vector
  - getEmbeddings(texts[]): Batch embedding generation
}

vectorDb.ts

IndexedDB operations:

Functions:
  - processFile(): Parse, chunk, embed, store document
  - searchVectors(): Cosine similarity search
  - getAllFiles(): Retrieve all documents
  - deleteFile(): Remove document and chunks
  - updateFileEnabled(): Toggle document in searches

AI Services

geminiService.ts and cerebrasService.ts:

Functions:
  - streamChatResponse(): 
      - Builds prompt with context
      - Streams AI response
      - Handles errors and retries

chatStorage.ts

Chat session management:

Functions:
  - saveChatSession(): Persist chat to localStorage
  - getChatSession(): Load specific chat
  - getAllChatSessions(): List all chats
  - deleteChatSession(): Remove chat
  - generateChatTitle(): Create title from first message

Data Flow

Document Upload Flow

  1. User uploads file

    File selected via input element

  2. File parsing

    Text extracted (PDF uses pdfParser, others use FileReader)

  3. Text chunking

    Split into 1000-char chunks with 200-char overlap

  4. Embedding generation

    Each chunk embedded locally via Transformers.js

  5. Storage

    Document metadata and chunk vectors saved to IndexedDB

  6. UI update

    Document appears in sidebar SOURCES tab

Query Flow

  1. User submits question

    Text entered in input field

  2. Query embedding

    Question embedded locally to create query vector

  3. Vector search

    Cosine similarity calculated against all enabled document chunks

  4. Result diversification

    Top results selected with diversity across documents

  5. Context preparation

    Relevant chunks formatted as context for AI

  6. AI request

    Query + context sent to Gemini or Cerebras API

  7. Response streaming

    AI response streamed back and displayed incrementally

  8. Citation display

    Source chunks shown as clickable citation badges

Storage Schema

IndexedDB

Database: ConstructLM_DB

Object Store: files

{
  id: string (UUID)
  name: string
  type: string (MIME type)
  size: number (bytes)
  uploadDate: number (timestamp)
  status: 'processing' | 'ready' | 'error'
  tokenCount: number
  isEnabled: boolean
}

Object Store: chunks

{
  id: string (UUID)
  docId: string (foreign key to files)
  text: string
  vector: number[] (384 dimensions)
  startIndex: number
  endIndex: number
}
Index: docId (for efficient deletion)

localStorage

Keys:
  - gemini_api_key: string
  - cerebras_api_key: string
  - chat_sessions: JSON array of ChatSession objects

Security Considerations

API Keys

  • Stored in localStorage (browser-local, not transmitted)
  • Never logged or exposed in UI (password fields)
  • Sent only in Authorization headers to respective APIs
  • User responsible for key security

Document Privacy

  • Documents embedded locally—never sent to embedding APIs
  • Only query + retrieved context sent to AI providers
  • Full documents remain in browser IndexedDB
  • No server-side storage or processing

XSS Protection

  • React's built-in XSS protection
  • Markdown rendered via react-markdown (sanitized)
  • No dangerouslySetInnerHTML usage

Performance Optimizations

  • Lazy Loading: Transformers.js model loaded on first use
  • Caching: Model cached in browser for offline use
  • Streaming: AI responses streamed for perceived speed
  • Debouncing: Input handling optimized
  • Virtual Scrolling: Efficient message list rendering
  • IndexedDB Indexes: Fast document lookup by docId
