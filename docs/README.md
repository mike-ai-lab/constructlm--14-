# ConstructLM Documentation

This directory contains the complete documentation for ConstructLM, a privacy-first RAG workspace.

## Documentation Structure

The documentation follows a hierarchical structure with four main sections:

### 1. Getting Started
- **index.html** - Introduction and overview
- **quick-start.html** - 5-minute setup guide
- **interface.html** - Complete UI component reference

### 2. Core Features
- **local-embeddings.html** - Privacy-first embedding system
- **rag-system.html** - Retrieval-Augmented Generation explained
- **ai-models.html** - Gemini and Cerebras integration
- **chat-management.html** - Conversation history and sessions

### 3. Advanced Features
- **api-configuration.html** - API key setup and testing
- **document-management.html** - Upload, enable/disable, delete documents
- **citations.html** - Source citation system

### 4. Reference
- **architecture.html** - Technical architecture overview
- **troubleshooting.html** - Common issues and solutions
- **tips.html** - Best practices and optimization tips

## Files

- **styles.css** - Professional documentation styling
- **docs.js** - Interactive features (TOC, smooth scroll, copy markdown)
- **[page].html** - Individual documentation pages

## Features

### Navigation
- Collapsible table of contents in left sidebar
- Auto-generated "On This Page" index in right sidebar
- Smooth scrolling to sections
- Active page highlighting

### Interactive Elements
- **Ask More** dropdown with:
  - Copy as Markdown
  - Ask ChatGPT (opens with page context)
- Responsive design (desktop, tablet, mobile)
- Print-friendly layout

### Design
- Clean, professional neutral design
- Orange accent color for highlights
- Optimized typography and spacing
- Mobile-responsive with collapsible sidebar

## Usage

1. Open `index.html` in a web browser
2. Navigate using the left sidebar TOC
3. Use "On This Page" for quick section jumps
4. Click "Ask More" for additional options

## Development

To add a new page:

1. Copy an existing HTML file as template
2. Update the `<title>` and main heading
3. Add content in the `<article>` section
4. Update TOC links in all pages to include new page
5. Ensure consistent navigation structure
