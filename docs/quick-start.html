Quick Start Guide

Get started with ConstructLM in just 5 minutes. This guide will walk you through the essential steps to start asking questions about your documents.

Step 1: Configure API Keys

Before you can use ConstructLM, you need to configure at least one AI model API key.

  1. Open Settings

    Click the ⚙️ settings icon in the sidebar (desktop) or header (mobile). If this is your first time, the settings modal will open automatically.

  2. Get API Keys

    You need at least one of these API keys:

    • Cerebras API (recommended for speed): Get from Cerebras Cloud
    • Gemini API (optional): Get from Google AI Studio
  3. Enter and Test Keys

    Paste your API key(s) into the respective fields. Click "TEST" to verify each key works correctly. You should see a green checkmark if successful.

  4. Save Configuration

    Click "SAVE" to store your keys. They are saved securely in your browser's localStorage and never leave your device.

Note:

API keys are stored locally in your browser. You'll need to reconfigure them if you clear your browser data or use a different browser.

Step 2: Upload Documents

Add documents to your knowledge base for the AI to reference.

  1. Navigate to Sources Tab

    In the sidebar, click the "SOURCES" tab to view your document library.

  2. Click "ADD SOURCE"

    Click the dashed box labeled "+ ADD SOURCE" to open the file picker.

  3. Select Files

    Choose one or more files to upload. Supported formats: TXT, MD, CSV, JSON, PDF. You can select multiple files at once.

  4. Wait for Processing

    The system will:

    • Parse the file content
    • Chunk the text into manageable pieces
    • Generate embeddings locally using Transformers.js
    • Store everything in IndexedDB

    Processing time depends on file size. A typical document takes 10-30 seconds.

First-Time Model Download:

The first time you upload a document, ConstructLM will download the embedding model (~25MB). This is cached for offline use afterward.

Step 3: Ask Questions

Now you're ready to interact with your documents!

  1. Select AI Model

    Choose between GEMINI or CEREBRAS using the toggle buttons in the header. On desktop, you can also select specific model variants from the dropdown.

  2. Type Your Question

    In the input field at the bottom, type a question related to your uploaded documents. For example: "What are the main features mentioned in the documentation?"

  3. Submit Query

    Press Enter or click the send icon. The system will:

    • Search your document embeddings locally
    • Find the most relevant text chunks
    • Send the query + context to the AI model
    • Stream the response back to you
  4. Review Answer with Citations

    The AI response will appear with source citation badges at the bottom. Click any citation to see the exact source text that was used.

Example Workflow

Here's a complete example to help you get started:

1. Upload: README.md, API_DOCS.md, USER_GUIDE.pdf
2. Wait: Processing completes (3 files, ~45 seconds)
3. Ask: "How do I configure the API settings?"
4. Review: AI provides answer with citations from API_DOCS.md
5. Explore: Click citation badges to see exact source passages
6. Follow-up: "What are the authentication options?"
7. Continue: Build on the conversation naturally

Tips for Success

  • Upload Related Documents: Group related documents together for better context
  • Use Specific Questions: More specific questions yield better answers
  • Check Citations: Always verify important information by reviewing the source citations
  • Enable/Disable Sources: Click on source cards to toggle them on/off for specific queries
  • Try Different Models: Gemini and Cerebras have different strengths—experiment to find what works best
  • Manage Chat History: Use the CHATS tab to revisit previous conversations
