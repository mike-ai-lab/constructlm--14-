Troubleshooting

Common issues and their solutions. If you encounter a problem not listed here, check the browser console for error messages.

API Key Issues

Invalid API Key Error

Symptom: Red X (✗) when testing API key, or "Invalid API key" error when sending messages.

Solutions:

  • Verify you copied the entire API key without extra spaces
  • Check that the key is from the correct provider (Gemini vs Cerebras)
  • Ensure the API key hasn't expired or been revoked
  • For Gemini: Get key from Google AI Studio
  • For Cerebras: Get key from Cerebras Cloud

API Key Not Saved

Symptom: Need to re-enter API keys after refreshing page.

Solutions:

  • Check if browser is in private/incognito mode (localStorage disabled)
  • Verify browser allows localStorage for the site
  • Check if browser extensions are blocking storage
  • Try a different browser

Rate Limit Errors

Symptom: "Rate limit exceeded" or "Too many requests" errors.

Solutions:

  • Wait a few minutes before trying again
  • Check your API provider's rate limits and usage
  • Switch to the other AI model temporarily
  • Upgrade your API plan if needed

Document Upload Issues

Upload Stuck or Very Slow

Symptom: Document processing takes extremely long or appears frozen.

Solutions:

  • First upload: Model download (~25MB) happens once—be patient
  • Large files: Files >1MB take several minutes to process
  • Check console: Open browser DevTools (F12) to see progress
  • Refresh page: If truly stuck, refresh and try again
  • Split files: Break very large documents into smaller files

PDF Parsing Fails

Symptom: Error when uploading PDF files.

Solutions:

  • Ensure PDF contains actual text (not scanned images)
  • Try converting PDF to TXT or MD format first
  • Check if PDF is password-protected (not supported)
  • Verify PDF isn't corrupted by opening in another app

Unsupported File Type

Symptom: File upload rejected or fails to process.

Supported formats:

  • .txt (Plain text)
  • .md (Markdown)
  • .json (JSON)
  • .csv (CSV)
  • .pdf (PDF with text)

Solutions:

  • Convert unsupported formats to TXT or MD
  • For Word docs: Save as TXT or copy/paste into TXT file
  • For images: Use OCR to extract text first

Embedding Issues

Model Download Fails

Symptom: Error during first document upload about model loading.

Solutions:

  • Check internet connection
  • Verify firewall isn't blocking HuggingFace CDN
  • Clear browser cache and try again
  • Try a different network
  • Wait and retry—CDN may be temporarily down

Embeddings Not Working Offline

Symptom: Can't upload documents when offline.

Explanation: Model must be downloaded once while online. After that, embeddings work offline.

Solutions:

  • Upload at least one document while online to cache model
  • Verify model is cached: Check browser storage in DevTools
  • If cache was cleared, reconnect to internet and upload a test file

Search & Query Issues

No Relevant Results Found

Symptom: AI says it can't find information, even though it's in your documents.

Solutions:

  • Check document is enabled: Click document card in SOURCES tab to enable
  • Rephrase query: Try different wording or keywords
  • Be more specific: Add context to your question
  • Check document content: Verify the information is actually in the uploaded files
  • Upload more context: Add related documents for better coverage

Wrong Sources Cited

Symptom: Citations don't seem relevant to the answer.

Explanation: Embedding similarity isn't perfect. The AI uses the provided context even if not ideal.

Solutions:

  • Click citations to verify what text was actually used
  • Rephrase your question to be more specific
  • Disable irrelevant documents in SOURCES tab
  • Upload more focused, relevant documents

Slow AI Responses

Symptom: Long wait time for AI to respond.

Solutions:

  • Cerebras: Usually very fast—check internet connection
  • Gemini: Can be slower during high load—try Cerebras
  • Large context: Many citations slow down response—disable some documents
  • API issues: Provider may be experiencing downtime

UI & Display Issues

Sidebar Not Visible

Symptom: Can't see sidebar on desktop.

Solutions:

  • Look for collapse/expand button on left edge
  • Click the button to expand sidebar
  • Refresh page if button is missing

Mobile Sidebar Stuck Open

Symptom: Can't close sidebar on mobile.

Solutions:

  • Tap the X button in top-right of sidebar
  • Swipe left to close
  • Tap the dark backdrop area
  • Refresh page if unresponsive

Markdown Not Rendering

Symptom: AI responses show raw markdown instead of formatted text.

Solutions:

  • Refresh the page
  • Clear browser cache
  • Check browser console for JavaScript errors
  • Try a different browser

Citations Not Showing

Symptom: No citation badges below AI responses.

Possible causes:

  • No documents uploaded yet
  • All documents disabled in SOURCES tab
  • Query didn't match any document content
  • Error during vector search (check console)

Performance Issues

Browser Becomes Slow

Symptom: Browser lags or becomes unresponsive.

Solutions:

  • Too many documents: Delete unused documents
  • Large documents: Split into smaller files
  • Memory: Close other tabs and applications
  • Old browser: Update to latest version
  • Clear data: Delete old chat sessions

High Memory Usage

Symptom: Browser uses excessive RAM.

Explanation: Embedding model and vectors consume memory.

Solutions:

  • Limit total documents to <500KB combined
  • Close and reopen tab to free memory
  • Use a device with more RAM
  • Delete unnecessary documents

Data & Storage Issues

Documents Disappeared

Symptom: Previously uploaded documents are gone.

Possible causes:

  • Browser data/cache was cleared
  • Using different browser or device
  • Private/incognito mode (data not persisted)
  • IndexedDB was manually deleted

Prevention:

  • Keep original document files as backup
  • Don't clear browser data for this site
  • Use same browser consistently
  • Avoid private/incognito mode for regular use

Chat History Lost

Symptom: Previous conversations are missing.

Causes:

  • localStorage was cleared
  • Different browser or device
  • Private/incognito mode

Note: Chat history is stored locally and cannot be recovered if deleted.

Using Browser Console

For advanced troubleshooting, open the browser console:

  1. Open DevTools

    Press F12 or right-click → "Inspect"

  2. Go to Console Tab

    Click "Console" at the top of DevTools

  3. Look for Errors

    Red text indicates errors. Copy error messages when reporting issues.

  4. Check Network Tab

    See API requests and responses for debugging API issues

Helpful Console Messages

ConstructLM logs useful information to the console, including RAG search results, citation counts, and API responses. Check the console for debugging details.

Getting Help

If you can't resolve an issue:

  • Check browser console for error messages
  • Try in a different browser to isolate the issue
  • Clear browser cache and try again
  • Verify internet connection is stable
  • Check API provider status pages
  • Review this documentation thoroughly
