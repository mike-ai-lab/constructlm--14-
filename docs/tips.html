Tips & Best Practices

Get the most out of ConstructLM with these proven strategies and optimization techniques.

Document Management

Choosing What to Upload

  • Quality over quantity: Upload focused, relevant documents rather than everything
  • Related content: Group related documents together for better context
  • Remove duplicates: Don't upload the same information multiple times
  • Clean formatting: Well-formatted documents yield better results
  • Text-based: Ensure PDFs contain actual text, not scanned images

Organizing Your Knowledge Base

  • Use descriptive names: Rename files before uploading for easy identification
  • Enable/disable strategically: Toggle documents on/off based on current task
  • Delete outdated content: Remove old versions when uploading updates
  • Monitor token usage: Keep an eye on the context usage meter
  • Split large files: Break documents >1MB into logical sections

Optimal File Sizes

File Size Recommendation Reason
< 100 KB Ideal Fast processing, good results
100-500 KB Good Reasonable processing time
500 KB - 1 MB Acceptable Slower processing, consider splitting
> 1 MB Split recommended Very slow, may cause issues

Asking Effective Questions

Question Formulation

  • Be specific: "How do I configure API keys?" vs "How does this work?"
  • Include context: "In the React component, how do I..." vs "How do I..."
  • Use keywords: Include terms that appear in your documents
  • Ask one thing: Break complex questions into multiple queries
  • Follow up: Build on previous answers in the conversation

Good vs Bad Questions

❌ Too vague:

  • "Tell me about this"
  • "What does it do?"
  • "Explain everything"

✅ Specific and clear:

  • "What are the steps to configure Gemini API key?"
  • "How does the local embedding system ensure privacy?"
  • "What file formats are supported for upload?"

Iterative Refinement

  1. Start broad

    "What are the main features?"

  2. Narrow down

    "Tell me more about the RAG system"

  3. Get specific

    "How does the similarity threshold work in vector search?"

Using Citations Effectively

Verifying Information

  • Always check citations: Click badges to see source text
  • Verify accuracy: Ensure AI interpretation matches source
  • Look for context: Read full citation text, not just preview
  • Cross-reference: Check multiple citations for consistency
  • Note similarity scores: Higher scores = more relevant

Citation Red Flags

  • Very low similarity scores (< 0.20)
  • Citations from unexpected documents
  • Source text doesn't match answer topic
  • Only one citation when multiple documents exist

Action: If citations seem off, rephrase your question or disable irrelevant documents.

AI Model Selection

Gemini vs Cerebras

Feature Gemini Cerebras
Speed Moderate ⚡ Very Fast
Quality Excellent Very Good
Context Length Very Large Large
Best For Complex analysis Quick answers
Cost Pay per use Pay per use

When to Use Each Model

Use Cerebras when:

  • You need fast responses
  • Asking straightforward questions
  • Iterating quickly through multiple queries
  • Working with smaller context

Use Gemini when:

  • Asking complex analytical questions
  • Need detailed explanations
  • Working with large amounts of context
  • Require nuanced understanding

Model Variants

  • llama3.1-8b: Fast, efficient, good for most tasks
  • gpt-oss-120b: More capable, slower, better reasoning
  • gemini-1.5-flash: Fast Gemini variant
  • gemini-1.5-pro: Most capable, best quality

Performance Optimization

Speed Up Document Processing

  • Use modern browser: Chrome/Edge have best WebAssembly performance
  • Close other tabs: Free up RAM and CPU
  • Upload during off-hours: Less browser activity = faster processing
  • Batch uploads: Upload multiple files at once
  • Smaller chunks: Split very large documents

Reduce Memory Usage

  • Keep total documents under 500KB combined
  • Delete old chat sessions regularly
  • Disable documents not currently needed
  • Refresh page periodically to clear memory
  • Use a device with adequate RAM (4GB+ recommended)

Improve Search Quality

  • Disable irrelevant docs: Reduces noise in search results
  • Use specific queries: Better matching with focused questions
  • Upload related content: More context = better answers
  • Check citations: Verify search is finding right content

Chat Management

Organizing Conversations

  • Start new chats: Begin fresh conversation for new topics
  • Descriptive first message: Helps with auto-generated titles
  • Delete old chats: Keep list manageable
  • Review history: Revisit previous conversations for reference

Conversation Strategies

  • Build context: Reference previous messages in follow-ups
  • Stay on topic: Keep conversation focused for best results
  • Clarify when needed: Ask AI to explain unclear points
  • Request examples: "Can you give an example?" often helps

Privacy & Security

Protecting API Keys

  • Never share keys: Keep API keys private
  • Use separate keys: Don't reuse keys across applications
  • Monitor usage: Check API provider dashboards regularly
  • Rotate keys: Change keys periodically for security
  • Revoke if compromised: Immediately revoke and replace exposed keys

Data Privacy Best Practices

  • Understand data flow: Documents stay local, only context sent to AI
  • Sensitive data: Be cautious with highly confidential information
  • Regular browser: Don't use incognito for regular work (data not saved)
  • Backup important docs: Keep originals—browser data can be cleared
  • Secure device: Use device-level security (passwords, encryption)

Advanced Tips

Using Browser DevTools

  • Console logs: See RAG search results and citation details
  • Network tab: Monitor API requests and responses
  • Application tab: Inspect IndexedDB and localStorage
  • Performance tab: Identify bottlenecks

Keyboard Efficiency

  • Enter: Submit message quickly
  • Tab: Navigate between UI elements
  • Esc: Close modals and dropdowns
  • F12: Open DevTools for debugging

Mobile Usage Tips

  • Swipe gestures: Swipe right to open sidebar, left to close
  • Tap citations: Pin tooltips for easier reading
  • Landscape mode: Better for reading long responses
  • Zoom: Pinch to zoom on citation text if needed

Do's and Don'ts

✅ Do

  • Upload clean, well-formatted documents
  • Ask specific, focused questions
  • Verify information using citations
  • Disable irrelevant documents
  • Keep total document size reasonable
  • Use descriptive file names
  • Test both AI models to find preference
  • Start new chats for new topics

❌ Don't

  • Upload duplicate content
  • Ask vague, open-ended questions
  • Trust answers without checking citations
  • Keep all documents enabled always
  • Upload files larger than 1MB without splitting
  • Use generic file names like "document1.txt"
  • Expect perfect answers without good source material
  • Mix unrelated topics in same chat
