Interface Overview

ConstructLM features a clean, brutalist-inspired interface designed for efficiency and clarity. This guide explains each component and how to use it effectively.

Main Layout

The interface consists of three main areas:

  • Sidebar (Left): Document and chat management
  • Chat Area (Center): Conversation interface with AI responses
  • Header (Top): Model selection and settings access

Header

Desktop Header

The desktop header contains:

  • Settings Icon (⚙️): Opens API configuration modal
  • App Title: "Construct_LM" branding
  • Model Dropdown: Select specific AI model variants (llama3.1-8b, gpt-oss-120b, gemini-1.5-flash, gemini-1.5-pro)
  • Model Toggle: Switch between GEMINI and CEREBRAS providers

Mobile Header

On mobile devices, the header is simplified:

  • Settings Icon: Quick access to configuration
  • Menu Button: Opens sidebar overlay
  • File Count: Shows number of indexed documents
  • Model Selector: Compact dropdown for model selection

Sidebar

The sidebar is your control center for managing documents and conversations.

Tabs

Two tabs organize different functions:

  • CHATS: View and manage conversation history
  • SOURCES: Manage uploaded documents

CHATS Tab

Features:

  • + New Chat Button: Start a fresh conversation
  • Chat List: All saved conversations with titles, message counts, and dates
  • Active Indicator: Current chat highlighted with border and shadow
  • Delete Option: Hover over chat to reveal "DEL" button

SOURCES Tab

Features:

  • + Add Source Button: Upload new documents
  • Document Cards: Each uploaded file shown with checkbox, name, and token count
  • Enable/Disable Toggle: Click card or checkbox to include/exclude from searches
  • Delete Option: Hover to reveal "DEL" button
  • Visual Feedback: Enabled sources have black border and shadow; disabled sources are faded

Context Usage Meter

At the bottom of the sidebar:

  • Shows total tokens across all documents
  • Progress bar indicates usage relative to 1M token limit
  • Turns red when approaching limits

Sidebar Resizing (Desktop)

On desktop, you can resize the sidebar:

  • Hover over the right edge of the sidebar
  • Cursor changes to resize indicator
  • Click and drag to adjust width (200px - 600px)
  • Click collapse/expand button to hide/show sidebar

Chat Interface

Message Display

Conversations are displayed in a clean, readable format:

  • User Messages: Right-aligned, black background, white text
  • AI Messages: Left-aligned, white background with border and shadow
  • Role Labels: Small uppercase labels ("YOU" / "CONSTRUCT_LM")
  • Markdown Rendering: Full support for formatting, code blocks, tables, lists

Citations Display

Below each AI response:

  • Citation Grid: 2-column grid of source badges
  • Source Badges: Show "SRC 1", "SRC 2", etc. with document name
  • Hover Tooltip: Displays highlighted preview and full context
  • Click to Pin: Click badge to keep tooltip open
  • Similarity Score: Shows relevance score at bottom of tooltip

Input Area

At the bottom of the chat:

  • Text Input: Type your question or message
  • Focus Effect: Input gains shadow when focused
  • Send Button: Click or press Enter to submit
  • Loading Indicator: Spinning icon while AI is responding
  • Disabled State: Input disabled while streaming response

Settings Modal

Access via settings icon (⚙️) in header:

API Key Configuration

For each AI provider (Gemini and Cerebras):

  • Input Field: Enter API key (password-masked by default)
  • Show/Hide Toggle: Eye icon to reveal/hide key
  • Test Button: Verify key works before saving
  • Status Indicator: Green checkmark (✓) or red X (✗) with error message
  • Get Key Link: Direct link to provider's API key page

Modal Actions

  • CANCEL: Close without saving changes
  • SAVE: Store keys in localStorage
  • Close (×): Top-right corner close button

Mobile Interface

Mobile Sidebar

On mobile devices:

  • Overlay Mode: Sidebar slides in from left as full-screen overlay
  • Dark Backdrop: Semi-transparent black background
  • Swipe Gestures: Swipe right to open, left to close
  • Swipe Indicator: Animated dots on left edge when closed
  • Close Button: X button in top-right of sidebar

Mobile Optimizations

  • Touch-friendly button sizes
  • Simplified header with essential controls
  • Full-width chat messages
  • Optimized citation tooltips (centered, scrollable)
  • Safe area insets for notched devices

Visual Design

Design Philosophy

ConstructLM uses a brutalist design approach:

  • Bold Borders: 2px black borders throughout
  • Hard Shadows: 4px offset shadows for depth
  • Monospace Font: Consistent mono typeface
  • Minimal Colors: Black, white, and gray with orange accents
  • Sharp Corners: No border radius (except specific UI elements)
  • High Contrast: Excellent readability

Interaction Feedback

  • Hover Effects: Subtle transforms and color changes
  • Active States: Shadow and border emphasis
  • Transitions: Smooth 300ms cubic-bezier animations
  • Loading States: Spinning indicators and progress bars

Keyboard Navigation

Efficient keyboard shortcuts:

  • Enter: Submit message in input field
  • Tab: Navigate between interactive elements
  • Esc: Close modals and dropdowns
  • Click Citations: Pin/unpin source tooltips
